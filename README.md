# ✈️ Sky Harbor — Kotlin + KorGE

**Sky Harbor** is an original air-traffic-control arcade game built with **Kotlin + KorGE** and exported for the web.

Your job is to guide aircraft safely toward their assigned runways while avoiding collisions and temporary weather zones.

## 🎮 Gameplay

1. Click an aircraft to select it.
2. Click an open point in the sky to change its route.
3. Guide the aircraft toward its assigned runway.
4. Keep aircraft separated.
5. Avoid storms because they drain fuel faster.
6. Land as many aircraft as possible before losing all lives.

## ✨ Features

- Kotlin game code
- KorGE game framework
- HTML5/JavaScript web target
- Original air-traffic strategy concept
- Three runways
- Multiple aircraft
- Collision detection
- Fuel system
- Weather/storm zones
- Score and landing rewards
- Lives
- Pause and restart
- Mouse/touch-friendly routing
- No backend
- No database
- No external API

## 🛠️ Requirements

- JDK 17+
- Gradle wrapper generated by the KorGE/Gradle setup

If the ZIP does not contain a Gradle wrapper on your machine, install Gradle or run the project through IntelliJ IDEA with the Gradle plugin.

## ▶️ Run

From the project root:

```bash
gradle jsBrowserDevelopmentRun
```

For a production web build:

```bash
gradle jsBrowserProductionWebpack
```

The generated browser distribution can then be served from a local HTTP server.

## 🌐 GitHub Pages

The repository contains:

```text
.github/workflows/deploy-pages.yml
```

Recommended setup:

1. Create a GitHub repository.
2. Upload the project.
3. Go to **Settings → Pages**.
4. Select **GitHub Actions** as the source.
5. Push to `main`.
6. Open the **Actions** tab and wait for the deployment.
7. Open the Pages URL generated by GitHub.
